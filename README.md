# News-1

Site de notícias de mercado — Brasil, Mundo e Catering Aéreo (Nacional /
Internacional). Código-fonte em [`news-site/`](./news-site).

Veja [`news-site/README.md`](./news-site/README.md) para instruções de
desenvolvimento, build e geração do artifact de arquivo único
(`news-site/bundle.html`).

## Manutenção Veicular

App de controle de manutenção de veículos (placa, km, data, pneus, elétrica,
vidros, limpador, óleo, freios e mais) em [`docs/manutencao/index.html`](./docs/manutencao/index.html).
Arquivo único, funciona offline; os dados ficam salvos no navegador (com backup JSON/CSV).
